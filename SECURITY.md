# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's **private vulnerability reporting** for the affected repository when available. Include:

- affected repository and component
- affected version, release, or commit
- clear description of the vulnerability
- reproducible steps or proof of concept
- potential impact
- known mitigations, if available

Please avoid including secrets or personal information in the report unless necessary for investigation.

## Scope

This policy applies to software maintained by ARC-V2-AI. Vulnerabilities in third-party dependencies should be reported to their maintainers when appropriate, but issues caused by how a dependency is integrated into an ARC-V2-AI project remain relevant to this policy.

## Disclosure

Please allow the maintainers reasonable time to investigate and address a vulnerability before public disclosure.
