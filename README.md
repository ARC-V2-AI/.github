# ARC-V2-AI `.github`

Organisation-wide GitHub configuration and community health files for **ARC-V2-AI**.

This repository provides the shared defaults used across ARC-V2-AI repositories, including:

- Organisation profile
- Contribution guidelines
- Pull request template
- Bug and feature-request templates
- Security policy
- Repository-wide GitHub conventions

Individual repositories remain authoritative for project-specific architecture, development commands, supported platforms, and release information.

## Organisation principles

ARC-V2-AI develops **local-first, service-oriented systems** with an emphasis on explicit architecture, persistent operation, and independently manageable components.

Repositories should prefer clear boundaries between installation, execution, supervision, and application capabilities rather than combining unrelated responsibilities into a single layer.
